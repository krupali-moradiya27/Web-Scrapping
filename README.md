# Web-Scrapping
Airline Web Scraping & ML Booking Prediction

📌Project Overview
This project focuses on web scraping airline customer reviews and predicting booking summaries using Machine Learning. The analysis includes sentiment classification, identifying key themes from customer feedback, and building a predictive model to determine booking outcomes.


🛠️ Technologies Used
Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn)
BeautifulSoup & Scrapy (for Web Scraping)
Machine Learning Models (Random Forest, Logistic Regression)
Natural Language Processing (NLP) (Text Preprocessing, Sentiment Analysis)
Visualization (Matplotlib, Seaborn, Power BI, Tableau)

📊 Analysis & Findings:
1️⃣ Sentiment Analysis on Airline Reviews
62% of British Airways reviews are positive, while 38% are negative.
Top Positive Themes: Comfort (23%), Service (20%), Food (17%)
Top Negative Themes: Delays (30%), Customer Service (25%), Baggage Issues (20%)
Key Insight: Improving customer service and delay management can significantly enhance customer satisfaction.
(Full analysis available in Airline_Analysis.pptx *)

2️⃣ Machine Learning Model for Booking Prediction
Random Forest Classification Model
Accuracy: 85.60%
Cross-validation Scores: [0.8509, 0.8461, 0.8492, 0.8497, 0.8503]
Key Features: Feature importance visualization available in ML report.
Evaluation Metrics: Precision, Recall, F1-score details are included.
(Full model details available in ML Model_ppt.pptx *)
